# Podcast Core Theme

A block (FSE) theme for podcast websites. Designed to work with [Podcast Core Plugin](https://github.com/rufusinfabula/podcast-core-plugin).

> Status: early development (0.1.0). Not ready for production.

## Planned features

- Home page: hero, latest episodes, latest news
- Episode template with the Podcast Core audio player
- Series archives
- Search results grouped by type (episodes, news, pages)
- Search overlay
- Style variations for different brands (`styles/`)

## Requirements

- WordPress 6.7+
- PHP 8.1+
- Recommended: Podcast Core Plugin
